# Atlas clothing authoring status

Clothing authoring is paused. The prior female base, body-region map, rig
reference, Wayfarer vest, and associated workspace were removed because the
underlying model rights were undocumented. There is no current Atlas body mesh
or skeleton to fit garments to.

Resume this workflow only after a licensed or original base mesh has passed
geometry review and its versioned skeleton, body regions, scale, and coordinate
frame are recorded. Clothing candidates must then be separately validated for
fit, skinning, deformation, provenance, license, and runtime budgets before
registration. The existing preparation/registration scripts still refer to the
retired base and must be updated before reuse.
