# Character reference intake

Only references with documented rights for the intended use may be copied into
this directory or measured for Atlas. The prior Bing Image Creator images and
derived silhouette record were removed on 2026-10-03 because project reuse
rights could not be verified. The Stone Troll profile is authored design input;
it is not a licensed observation or independent learning example.

The currently retained external model references are documented with source,
license, and checksums in [`../sources/README.md`](../sources/README.md). Keep
those source files in the ignored cache and do not treat them as accepted Atlas
geometry. A future reference record must include its source URL, license,
checksum, allowed uses, review status, and lineage before it contributes to
measurements or recipe-learning evidence.
