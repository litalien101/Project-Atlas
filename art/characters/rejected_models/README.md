# Rejected character candidates

This directory preserves generated trials that failed review. Archived files
are evidence only: they are not approved source geometry, runtime assets,
training examples, or candidates to advance to later pipeline stages without a
new review. Keep the review record with each trial and identify its output by
SHA-256.

Each subdirectory groups by character; each trial directory is named for the
preview GLB's SHA-256 so later builds cannot silently replace rejected
evidence. New trials belong under `art/characters/pending_models/`.
