# Character Pipeline Audit

The current pipeline is a local deterministic authoring prototype:

- Neutral design-profile schema and starter profile.
- Explicit-value text compiler with preservation of unparsed brief text.
- Recipe and frozen geometry-build-plan compilers.
- Blender blockout generator and local Recipe Studio candidate gallery.
- Source inspection and technical screening for upright humanoid references.

The prototype does not include a designed character, production topology,
finished material generation, an approved observation dataset, a learning
miner, a rig/weight generator, animation authoring, or runtime character
registration.

## Next work

1. Approve the new design brief and references.
2. Replace the blockout construction with topology-aware, reviewable geometry.
3. Freeze and hash every input and output; tie review records to build IDs.
4. Add explicit stage-specific contracts for materials, rigging, animation, and
   release only when those stages are implemented.
5. Keep rights, quality, lineage, learning eligibility, and runtime approval as
   distinct human-reviewed decisions.
